# ADR-0005: 带 tools 的流式——立即 200 + role chunk + keepalive、正文缓冲

- 状态：已接受
- 日期：2026-07-21

## 背景

M365 substrate 是快照式吐字（非干净 token 增量）。现有 proxy 对带 tools 的请求整轮缓冲，客户端要干等整轮解析完才收到首字节，长轮次易触发 read-timeout。不同 agent 的超时阈值不一。

## 决策

带 tools 的流式请求：
- **立即返回 HTTP 200**；
- 先发一个 **role chunk**；
- 每 ~15s 发一个 **keepalive 注释**；
- **正文仍缓冲**，直到工具调用解析完整后再发（避免把未闭合的围栏片段吐给客户端导致误解析）。

无 tools 的流式请求：走真增量透传（含 prefix-safe 的快照/增量折叠，防丢头/重复）。

## 理由

- 解决长轮次 read-timeout（通用网关硬需求）。
- 不牺牲工具调用正确性；纯客户端改动，无副作用。

## 后果

- 带 tools 时首字节是 role/keepalive，正文延迟到解析完成——这是可靠性与延迟的折中。
